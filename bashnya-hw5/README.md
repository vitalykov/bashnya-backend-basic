# Домашнее задание №5. Многопоточность

## 📅 Дедлайн: 17 ноября, 23:59

На Linux и MacOS можно протестить задания с помощью Makefile
```shell
make taskN # N - номер задания
```

## Задание 1 ✅
Дана последовательность чисел: 2, 4, 6, 8, 10. Найти сумму их квадратов (2² + 3² + 4² + …) с использованием конкурентных вычислений.
+ summator package

## Задание 2 ✅
Реализовать постоянную запись данных в канал (главный поток). Реализовать набор из N воркеров, которые читают произвольные данные из канала и выводят в stdout. Необходима возможность выбора количества воркеров при старте.
Программа должна завершаться по нажатию Ctrl+C. Необходимо выбрать и обосновать способ завершения всех воркеров, а также реализовать корректный выход горутин через контекст
+ printer package. CLI program in cmd/printer

## Задание 3 ✅
Реализовать конкурентную запись данных в map.
+ safemap package

## Задание 4 ✅
Разработать конвейер чисел. Даны два канала: в первый пишутся числа (x) из массива, во второй — результат операции x*2, после чего данные из второго канала должны выводиться в stdout.
+ pipeline package. CLI program in cmd/pipeline
